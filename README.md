# FirstLook Photo Insights

the name of the app is FirstLook


Enable the backend (Lovable Cloud) for auth, database, and storage. For the photo analysis, use Lovable’s built-in AI with a Gemini vision model through a backend function, so no API key is needed.

This project was built with [Lovable](https://lovable.dev).
